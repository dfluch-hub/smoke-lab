# SMOKE LAB v18 — Guided UX / Commercial Polish

## Core change
SMOKE LAB now explains the next useful action before presenting analytics. The product should feel guided rather than like a dashboard the user has to decode.

## Implemented in this pass
- Added a clear **NOW / JETZT** orientation card on Today.
- Moved immediate behavior actions before analytics so the user acts before interpreting metrics.
- Added a short **What is happening right now?** decision label above the two primary actions.
- Added an explicit **NEXT / ALS NÄCHSTES** card in the 30-day Lab with a direct CTA to today’s mission.
- Increased bottom-navigation safe-area spacing for iPhone/Safari/PWA.
- Added extra app-shell bottom clearance so content is not visually trapped behind the navigation.
- Bumped app version to **0.18.0**.

## v18 product principle
One screen = one clear question = one obvious next action.
