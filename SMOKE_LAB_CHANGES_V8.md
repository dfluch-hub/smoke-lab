# SMOKE LAB v8 — Quit / Recovery / High-Risk Support

- Added optional quit date without streak, countdown pressure or reset logic.
- Added locally stored protection plans for repeated difficult trigger + place + time contexts.
- High-risk signals require repeated multi-day user evidence and are explicitly descriptive, not clinical predictions.
- Matching protection plans can now influence the intervention shown in Craving Mode.
- Added compassionate lapse-recovery flow after a cigarette logged on/after the optional quit date.
- Recovery asks only a few useful questions and preserves all prior progress.
- Recovery records and quit-support plans are included in JSON data export and cleared by full data reset.
- Added linked-event de-duplication to high-risk signal analysis.
- Added quit/recovery engine tests.
