# SMOKE LAB v0.9 — Integration & Continuity

This version consolidates four product layers without changing the approved visual identity.

## Weekly Review
- Real rolling 7-day review built only from local logs.
- Never fabricates future trends or causal improvement.
- Shows observations, interruptions, average urge, intentional decisions, reassessment outcomes, and a cautious next focus.
- Only makes comparison statements when the previous 7-day window contains enough data.

## Maintenance after Day 30
- The 30-day Lab no longer ends in a dead screen.
- A lightweight weekly maintenance plan appears after Journey completion.
- It focuses on the clearest current loop, one practiced strategy, and keeping the Control Plan current.
- No streak and no daily-perfect-use requirement.

## Control Plan 2.0
- Combines the Personal Control Model with goal-specific preparation and available high-risk planning.
- Produces a concise living plan of up to five grounded steps.
- Continues to distinguish working signals from clinical conclusions.

## Experiment Library
- Adds the eight core behavioral experiments from the product specification.
- Sorts likely-relevant tests first using the strongest observed trigger and onboarding cues.
- A manually selected library test becomes a three-attempt personal experiment.
- It does not replace or silently interrupt an already-active personal experiment.

## Data portability
- JSON export now includes the current weekly review, Control Plan 2.0, and Maintenance plan.

## Quality
- New pure-engine integration tests cover the v9 features.
- All TypeScript/TSX files were syntax-transpiled successfully.
- New behavior-engine files pass TypeScript type checking independent of external UI packages.
